## The one rule

**KD_INFO.md is the source of truth.**

Every fact on the website traces back to it. If a number needs to change, it changes in KD_INFO.md first,
and everything else follows. If a fact is not in KD_INFO.md, it is not approved for publication — add it
there, with its source, before using it anywhere.

---

## Verification markers

KD_INFO.md marks every fact with its confidence level. This is not decoration — the source documents
insist repeatedly on separating what the company actually said from what was researched or proposed, and
on a website that faces government tender evaluators, publishing an unverified claim is a real problem.

| Marker | Meaning | Publishable? |
| --- | --- | --- |
| ★ **Approved** | From `K.D.Website_Details.docx` — company-approved. **Overrides everything.** | Yes |
| ✅ **Verified** | From an earlier company document, not contradicted by the approved doc | Yes |
| 🌐 **Industry** | External research | Yes — but must be visibly labelled as external context |
| 🟡 **Unconfirmed** | Ambiguous, inconsistent, or carried over from an earlier document the approved doc does not mention | **No** — confirm first |
| ⬜ **Missing** | Needed but absent everywhere | **No** — collect it |

**On silence.** The approved document does not restate everything the earlier documents said. Silence is
not contradiction — those facts are kept, but demoted to 🟡. The full list of what fell into that category
is at the end of [KD_INFO.md](KD_INFO.md#appendix--what-changed-in-revision-3).
