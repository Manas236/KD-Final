### Four things that are true about this library

1. **It is 90% "finished building, daylight, no people, no machines."** Almost nothing shows construction
   happening. That rules out an L&T / Afcons action-photography homepage — the design has to carry the
   page and let a few strong photographs punctuate it.
2. **The resolution is inverted.** The 6000×4000 pro DSLR shoot (83 frames) is almost entirely the
   Matunga *office block* — corridors, meeting rooms, potted plants. The photographs of actual railway
   engineering — the shed interior, the Vande Bharat trainset, the gantry cranes — are 1024–1280 px web
   exports. **The impressive subjects are the low-resolution ones.**
3. **Three folders are near-duplicates of one frame.** Sanpada = 38 WhatsApp shots of one building from
   one angle. Safety/Mankhurd = ~40 near-identical certificate-handshake frames at one wall. Matunga = 60
   office interiors.
4. **The best pictures are the FOBs.** Vashi and Bonkode are the only sets that are simultaneously
   high-resolution, well composed, and unmistakably *infrastructure*.

## 11. Handling rules

**Storage.** The source media is ~3.6 GB. **It must never enter git.** Keep originals outside the repo
(or gitignored) and commit only web-optimised derivatives. Git history cannot be trimmed afterwards
without a force-push rewrite.

```
kd-assets/                    ← outside the repo, or gitignored
  harbour-line-fobs/
  matunga-workshop/
  nhava-sheva-uran-stations/
  ...
        │  resize · strip EXIF · WebP + JPEG (AVIF once encode time is tuned)
        ▼
public/img/<project-slug>/    ← committed, derivatives only
```

**Derivative widths:** `400` card · `800` gallery · `1600` band · `2400` hero.

**Strip EXIF.** Phone photos in this set carry GPS coordinates.

**De-duplicate before building any gallery** — 12 duplicates in Matunga, 6 in `Safety Department/08-01-2026
Mankhurd/New folder/` (a literal folder of re-copies), 2 in Sanpada.

**Alt text.** Every image, not just heroes. Name the project and the client, using the **approved
spellings** — Nhava Sheva, Ulwe, Gindodia.

**Watermarks.** `matunga 2.jpeg` carries a "Shot on OnePlus" mark bottom-left; trim the bottom ~11%.
Check any new phone export for the same.

**Clearance still needed:** whether the Vande Bharat trainset inside Matunga Workshop is approved for
public use, and permission to display client logos and ISO certification marks.
